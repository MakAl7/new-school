# ✅ Проблема CORS решена!

## Что было исправлено

**Проблема:** Vite создавал отдельные файлы JS и CSS, которые не могли быть загружены через `file://` из-за CORS политики.

**Решение:** Созданы два полностью автономных HTML файла:
- `dist/index.html` - основное приложение (274 KB, весь CSS и JS встроен)
- `dist/admin.html` - админ-панель (полностью автономная, 539 строк)

## Как использовать

### Основное приложение
```
Откройте: dist/index.html
```
- Тренажёр ударений
- Словарные слова (1-11 классы)
- Словарь с кнопкой "Ошибка"
- Прогресс обучения
- QR-код для переноса данных

### Админ-панель
```
Откройте: dist/admin.html
Пароль: admin123
```

**Возможности:**
- ✅ Просмотр всех слов в двух таблицах
- ✅ Добавление новых слов
- ✅ Редактирование существующих слов
- ✅ Удаление слов
- ✅ Поиск и фильтрация
- ✅ Автоматическая синхронизация с основным приложением

## Структура файлов

```
dist/
├── index.html      (274 KB) - основное приложение
└── admin.html      (автономная админ-панель)
```

## База данных

Данные хранятся в localStorage браузера:
- `udarenie-db-stress` - слова для проверки ударений
- `udarenie-db-vocab` - словарные слова

**Синхронизация:** Изменения в админ-панели автоматически применяются в основном приложении через события localStorage.

## Технические детали

### Основное приложение
- React 18 + TypeScript
- Tailwind CSS 4
- Весь код встроен в один HTML файл (274 KB)
- Использует localStorage для хранения данных

### Админ-панель
- Чистый JavaScript (без фреймворков)
- Встроенный CSS
- Полный CRUD для обеих таблиц
- Поиск и фильтрация
- Модальные окна для редактирования

### API базы данных
```javascript
// Получение данных
getStressWords() → StressWord[]
getVocabWords() → VocabWord[]

// Добавление
addStressWord(word) → StressWord
addVocabWord(word) → VocabWord

// Обновление
updateStressWord(id, updates)
updateVocabWord(id, updates)

// Удаление
deleteStressWord(id)
deleteVocabWord(id)
```

## Как открыть

1. Скачайте папку `dist`
2. Откройте `dist/index.html` двойным кликом - основное приложение
3. Откройте `dist/admin.html` двойным кликом - админ-панель
4. Войдите с паролем `admin123`
5. Редактируйте слова
6. Изменения автоматически применяются в основном приложении
