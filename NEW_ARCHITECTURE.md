### База данных (localStorage)

**Таблица "Слова для проверки ударений":**
- `id` - уникальный идентификатор
- `word` - слово
- `stress` - индекс ударной гласной (0-based)
- `hint` - подсказка
- `difficulty` - сложность (1-3)

**Таблица "Словарные слова":**
- `id` - уникальный идентификатор
- `word` - слово
- `missing` - проверяемая буква/сочетание
- `options` - варианты ответа
- `hint` - подсказка
- `class` - класс (1-11)
- `emoji` - эмодзи (опционально)

### Синхронизация данных

Основное приложение автоматически обновляется при изменениях в базе данных через:
- Событие `storage` (для синхронизации между вкладками)
- Пользовательское событие `db-updated` (для синхронизации в рамках одной вкладки)

### API базы данных

```typescript
// Получение данных
getStressWords(): StressWord[]
getVocabWords(): VocabWord[]

// Добавление
addStressWord(word: Omit<StressWord, "id">): StressWord
addVocabWord(word: Omit<VocabWord, "id">): VocabWord

// Обновление
updateStressWord(id: string, updates: Partial<StressWord>): void
updateVocabWord(id: string, updates: Partial<VocabWord>): void

// Удаление
deleteStressWord(id: string): void
deleteVocabWord(id: string): void

// Подписка на изменения
onDatabaseChange(callback: () => void): () => void

// Сброс
resetDatabase(): void

// Статистика
getDBStats(): { stressCount: number; vocabCount: number; version: number }
```

### Как использовать

#### Основное приложение
1. Откройте `dist/index.html`
2. Работает как обычно
3. Автоматически читает данные из базы данных
4. Автоматически обновляется при изменениях в админке

#### Админ-панель
1. Откройте `dist/admin.html`
2. Введите пароль: `admin123`
3. Редактируйте таблицы:
   - Добавляйте новые слова
   - Редактируйте существующие
   - Удаляйте ненужные
4. Изменения автоматически применяются в основном приложении
