# Как запустить приложение "Ударе́ние!"

## Проблема: пустой экран

Если вы видите пустой экран, значит открываете **неправильный файл**.

## Решение

### ✅ ПРАВИЛЬНО: Откройте файл из папки `dist`
1. Перейдите в папку `dist`
2. Откройте файл `dist/index.html` двойным кликом
3. Приложение откроется в браузере

### ❌ НЕПРАВИЛЬНО: Открывать корневой index.html
- НЕ открывайте `index.html` из корня проекта
- Это исходный файл для разработки, он не работает напрямую

## Альтернативные способы

### Способ 1: Через локальный сервер
```bash
npm install
npm run dev
```
Затем откройте http://localhost:3000

### Способ 2: Собрать заново
```bash
npm install
npm run build
```
Затем откройте `dist/index.html`

## Проверка

После открытия `dist/index.html` вы должны увидеть:
- Заголовок "Ударе́ние!"
- Навигацию с вкладками: Ударения, Словарные слова, Словарь, Прогресс, QR-код
- Тренажёр с карточками слов

Если видите ошибку - откройте консоль браузера (F12) и посмотрите сообщение об ошибке.
