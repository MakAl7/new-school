# 🔊 Озвучка добавлена!

## Что нового

Добавлена функция озвучивания (text-to-speech) для:
- **Химических элементов** таблицы Менделеева
- **Слов с ударениями** в словаре

## Как это работает

### Для химических элементов:
1. Откройте вкладку **"Химия"**
2. Кликните по любому элементу
3. В карточке элемента вы увидите:
   - Название на русском
   - Название на английском
   - **Произношение на латинице** в квадратных скобках `[...]`
   - **Кнопку 🔊** для озвучивания названия

**Пример:**
```
Водород
Hydrogen
[Vodorod] 🔊
```

### Для слов с ударениями:
1. Откройте вкладку **"Русский язык" → "Словарь"**
2. Найдите любое слово
3. Под словом с ударением вы увидите:
   - **Произношение на латинице** с ударением `'`
   - **Кнопку 🔊** для озвучивания

**Пример:**
```
то́рты
[to'rty] 🔊
💡 То́рты — как шо́рты
```

## Технические детали

### Транслитерация
Произношение генерируется автоматически из русского текста с использованием стандартной транслитерации:

| Кириллица | Латиница |
|-----------|----------|
| а | a |
| б | b |
| в | v |
| г | g |
| д | d |

| ё | yo |
| ж | zh |

| ч | ch |

| щ | shch |
| ъ | (пропуск) |
| ы | y |
| ь | (пропуск) |
| э | e |
| ю | yu |
| я | ya |

### Ударения
- В словах с ударениями ударная гласная обозначается символом `'` (апостроф)
- Пример: `то́рты` → `[to'rty]`

### Озвучивание
Используется **Web Speech API** (встроенный в браузер):
- Язык: русский (`ru-RU`)
- Скорость: 0.8 (чуть медленнее обычной)
- Работает во всех современных браузерах

## Как использовать

### В основном приложении:
1. Откройте `dist/index.html`
2. Перейдите на вкладку "Химия" или "Русский язык → Словарь"
3. Найдите слово или элемент
4. Нажмите кнопку 🔊 для озвучивания

### Требования:
- Современный браузер с поддержкой Web Speech API
- Chrome, Firefox, Edge, Safari (последние версии)
- Работает офлайн (использует встроенный синтезатор речи)
