# Ударе́ние! — тренажёр русского языка

PWA-приложение для изучения ударений и словарных слов русского языка.

## Как запустить

### Вариант 1: Открыть готовую сборку
Откройте файл `dist/index.html` в браузере (двойной клик).

### Вариант 2: Запустить в режиме разработки
```bash
npm install
npm run dev
```
Затем откройте http://localhost:3000

### Вариант 3: Собрать production-версию
```bash
npm install
npm run build
```
Затем откройте `dist/index.html`

## Функции

- **Ударения** - тренажёр и экзамен по ударениям (26 базовых слов)
- **Словарные слова** - изучение словарных слов по классам (1-11 классы, 476 слов)
- **Словарь** - справочник всех слов с поиском
- **Прогресс** - статистика обучения
- **QR-код** - перенос прогресса между устройствами

## Технологии

- React 18
- TypeScript
- Tailwind CSS 4
- Vite
- PWA (Progressive Web App)

## Структура данных

- `src/data/words.ts` - базовые слова для проверки ударений
- `src/data/stress-words.ts` - дополнительные слова с ударениями
- `src/data/vocab.ts` - словарные слова по классам
- `src/data/vocab-words-extra.ts` - дополнительные словарные слова
