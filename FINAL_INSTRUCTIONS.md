# ✅ Приложение "Ударе́ние!" готово к использованию

## Как запустить

### ✅ ПРАВИЛЬНЫЙ СПОСОБ:
1. Откройте папку `dist`
2. Найдите файл `index.html`
3. Откройте его двойным кликом в браузере
4. Приложение запустится!

### ❌ НЕПРАВИЛЬНО:
- НЕ открывайте `index.html` из корня проекта
- Это исходный файл для разработки

## Что включено

### Вкладки приложения:
1. **Ударения** - тренажёр и экзамен по ударениям
   - 26 базовых слов с разными уровнями сложности
   - Режимы: Тренажёр (обучение) и Экзамен (проверка)
   
2. **Словарные слова** - изучение словарных слов по классам
   - 1-11 классы (68 слов в базовой версии)
   - Режимы: Учим (карточки) и Проверяем (диктант)
   
3. **Словарь** - справочник всех слов с поиском
   - Поиск по словам
   - Фильтры по сложности
   - Отметки "выучено"
   
4. **Прогресс** - статистика обучения
   - Точность ответов
   - Серия занятий
   - История экзаменов
   - Прогресс по классам
   
5. **QR-код** - перенос прогресса между устройствами

## Структура данных

### Базовые слова (src/data/words.ts):
- 26 слов для проверки ударений
- 3 уровня сложности

### Словарные слова (src/data/vocab.ts):
- 68 слов по классам (1-4 классы)
- С пропусками букв для тренировки

### Дополнительные данные:
- `stress-words.ts` - 197 дополнительных слов с ударениями
- `vocab-words-extra.ts` - 476 дополнительных словарных слов
